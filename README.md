# About VGMod:
VGMod adds additional client side functionality for the Vanilla Games Minecraft server! IP: play.vanillagames.net
# Features:
### Custom commands
- /vghelp -> displays custom VGMod commands
- /vglobby -> sends you to the Vanilla Games lobby no matter where you are
- /vgstats -> displays all your Vanilla Games stats
- /vgrules -> displays the Vanilla Games rules
- /vgranks -> displays the Vanilla Games ranks
- /vginfo -> displays the Vanilla Games server info
- /vgbeans -> displays your choko beans
- /vghats -> opens the hat selection ui
- /vgparticles -> opens the particle selection ui
- /vgtitles -> opens the titles selection ui
- /vgfriend [add/remove/list] [username] -> configures your VG friends! When a VG friend joins the server, you will recieve a subtitle announcing their arrival
- /vgfriendsetdisplay [subtitle/chat/none] -> changes or disables the display method for friends who join
- /vgsb [invite/nether/end/wither/animals -> quickly sends a chat message explaining to new players how to invite friends to their SB island, reach the nether/end, or how passive animals work
- /vgjoin [game] -> teleports you to the game lobby that you specify
- /vgtogglewbmessages [true/false] -> enables/disables the automatic welcome back feature
### Lobby keybind
- VGMod adds a hotkey keybind option to teleport to the lobby (which can be a lot faster than relogging if you fall into the void from your SB island)! XD
